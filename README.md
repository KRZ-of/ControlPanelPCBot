# PC Telegram Bot

Telegram-бот для управления Arch Linux / Hyprland-компьютером с телефона.

Бот работает через Telegram Long Polling и не требует открывать порт или веб-интерфейс.

## Возможности

- 🔊 Управление громкостью через PipeWire / WirePlumber
- 🔇 Включение и выключение звука
- 🎵 Управление музыкой через `playerctl`
- 🔒 Блокировка текущей сессии
- 🖥 Переключение рабочих столов Hyprland
- 🔐 Ограничение доступа по Telegram User ID
- ⚙️ Команды и их подписи задаются через `config/config.json`

## Команды Telegram-бота

| Команда | Подпись | Действие |
|---|---|---|
| `/start` | Главное меню | Показывает список доступных команд |
| `/volume_up` | Увеличить громкость | Увеличивает громкость на 5% |
| `/volume_down` | Уменьшить громкость | Уменьшает громкость на 5% |
| `/mute` | Выключить/включить звук | Переключает mute |
| `/play` | Воспроизведение/пауза | Play / Pause текущего медиаплеера |
| `/next` | Следующий трек | Переключает на следующий трек |
| `/previous` | Предыдущий трек | Переключает на предыдущий трек |
| `/lock` | Заблокировать компьютер | Блокирует текущую Linux-сессию |
| `/workspace N` | Перейти на рабочий стол | Переключает Hyprland на рабочий стол `N` |
